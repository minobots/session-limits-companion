Session Limits — Codex companion

A tiny helper so the app can show your Codex usage.

Codex / ChatGPT has no usage API, so a small program on the Mac where you use codex reads the numbers from your logged-in CLI and serves them to the app on your local network. Nothing else leaves the machine. MiniMax, OpenCode Go and Claude don't need this — they connect directly in the app.

Install

Paste this in Terminal on that Mac:

curl -fsSL https://raw.githubusercontent.com/minobots/session-limits-companion/main/install.sh | sh
Download double-click installer

The download is a .command file — double-click it (first time: right-click → Open). Either way it fetches the helper, installs it as a login item, and prints a pairing QR.

Pair

  1. Run the line above — a QR prints in the terminal.
  2. In the app: Settings → Companion app → Scan pairing code.
  3. Turn on Codex in Services.

The QR carries this machine's own address and a unique token — you pair your own account, nobody else's. Re-run the line any time to reprint it. Off your home network, put both devices on the same Tailscale tailnet.

Uninstall

launchctl unload ~/Library/LaunchAgents/com.sessionlimit.sessiond.plist
rm ~/Library/LaunchAgents/com.sessionlimit.sessiond.plist
rm -rf ~/.session-limit-tracker
